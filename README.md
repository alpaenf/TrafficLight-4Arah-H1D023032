# Traffic Light 4 Arah Arduino

## Deskripsi
Project ini merupakan simulasi traffic light 4 arah menggunakan Arduino Uno dan Tinkercad.

## Fitur
- 4 arah (Utara, Timur, Selatan, Barat)
- LED merah, kuning, hijau
- Sistem looping otomatis
- Kuning berkedip 3x
